Development setup

- To start the backend server:
	- cd backend
	- npm install
	- npm run dev

- Admin and test user credentials are NOT stored in this file. Use the seeding script to create initial accounts:
	- Set `SEED_ADMIN_PASSWORD` and `SEED_USER_PASSWORD` in your environment (or let the seeder generate random passwords).
	- Run: `npm run seed`

- For payment gateway testing, use your provider's sandbox/test credentials configured through environment variables. Do NOT commit real card details or API keys.

Security note: This file previously contained plaintext credentials and demo card data. Those values have been removed. Keep secrets in environment variables or your hosting provider's secrets manager.
